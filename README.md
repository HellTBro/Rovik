# Rovik — Studio Music Desktop Player

A modern, minimalist music player for Windows desktop, featuring a 32-bit DSP audio engine, synchronized dual-line lyrics, and an offline music vault.

Official Channel: [YouTube (@Hell_BroX)](https://www.youtube.com/@Hell_BroX)

---

## Download and Installation (Windows)

1. Download the latest installer: [`Rovik Setup 1.0.0.exe`](./Rovik%20Setup%201.0.0.exe)
2. Run the installer on Windows 10 or Windows 11.
3. Launch Rovik and enjoy music.

## Core Capabilities

### 1. Studio Audio Engine
- 32-bit floating point Web Audio DSP pipeline.
- 10-Band Graphic Equalizer with studio presets.
- Real-time Studio Spectrum Analyzer with FFT-based frequency bars.
- Pitch-preserving variable playback speed (0.5x – 2.0x).
- Playback queue with reordering, shuffle, repeat-queue, and single-track loop modes.
- Hardware media keys and Windows MediaSession integration.

### 2. Lyrics Canvas and Karaoke
- Fullscreen Canvas with synchronized LRC lyrics.
- Dual-Mode Lyrics Architecture:
  - Two-Line Focus (Default): Active vocal illumination with smooth focus transitions.
  - Adaptive Smooth Flow: Intelligent text-aware liquid light wave automatically adapting speed to syllable density and rhythm.
- Custom atmospheric aura glow and natural typography without jitter.

### 3. Catalog and Offline Music Vault
- Direct integration with YouTube Music streams, Audius decentralized catalog, and Rovik releases.
- Offline Vault ("My Music"): Complete local playback with IndexedDB caching and direct disk import (.mp3, .flac, .wav, .ogg, .m4a).
- Non-blocking top-left download manager with concurrent download queuing and live progress tracking.

### 4. Interface and Customization
- Refined frosted glass design with dark studio palette.
- Dynamic background engine supporting custom images, video wallpapers, and artist banners.
- Granular control over background dimming, blur, surface transparency, and corner curvature.
- Strict absence of neon artifacts and cluttered borders.
- Full bilingual interface (Russian and English).
